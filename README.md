# dstfarm

Консольное приложение на .NET 10 с полноэкранным TUI (Spectre.Console): само разворачивает
выделенный сервер Don't Starve Together, генерирует мир под идл-фарм и держит сервер живым.

## Как на самом деле работает фарм дропов Klei

Дропы начисляются **аккаунту игрока, который находится в игре**, а не серверу. Выделенный
сервер сам по себе ничего не нафармит — он даёт мир, где персонаж может стоять сутками:
не умрёт, не сойдёт с ума, не будет съеден, и который не грузит машину. Клиент подключаете
сами и оставляете запущенным.

Без этих двух вещей дропов не будет:

* `offline_cluster = false` в `cluster.ini` — офлайн-мир не идёт в зачёт игрового времени.
  Утилита всегда пишет `false`, поменять из интерфейса нельзя.
* `cluster_token.txt` — токен из аккаунта Klei. Без него сервер просто не стартует.

У Klei есть недельный лимит на дропы: аптайм сверх него ничего не добавляет.

## Установка готовой сборки

Возьмите `dstfarm.exe` из [релизов](../../releases) — это self-contained сборка под
Windows x64, .NET на целевой машине не нужен. Положите в отдельную папку: рядом с exe
появятся `config.json` и `.runtime` с сервером, логами и статистикой.

## Сборка и запуск

```
dotnet build
dotnet run --project src/DstFarm.Cli
```

Релизная сборка — один self-contained exe без зависимостей:

```
dotnet publish src/DstFarm.Cli -c Release
```

## Интерфейс

Запуск без аргументов открывает полноэкранный режим: слева настройки фарма, справа статус,
снизу живой лог сервера.

```
стрелки ↑↓   выбор строки
стрелки ←→   менять значение (для флагов — переключить)
Enter        править текстовое поле (имя сервера, пароль, токен)
S            запустить / остановить сервер
I            установить или обновить сервер через steamcmd
G            записать настройки в файлы кластера
F1           подсказка
Q / Esc      выход (настройки сохраняются)
```

Если ввод или вывод перенаправлен (пайп, CI), полноэкранный режим не включается —
приложение печатает статус и подсказку.

## Команды

| Команда | Что делает |
| --- | --- |
| `dstfarm` | полноэкранный интерфейс |
| `dstfarm install [--no-validate]` | steamcmd + установка/обновление сервера (app 343050, вход анонимный) |
| `dstfarm init [--force]` | генерирует `cluster.ini`, шарды, `worldgenoverride.lua` |
| `dstfarm token <ТОКЕН>` | записывает `cluster_token.txt` |
| `dstfarm start [--detach]` | супервизор: запускает шарды, перезапускает при падении |
| `dstfarm stop` | штатная остановка через `c_shutdown(true)` — мир сохраняется |
| `dstfarm status` | состояние и накопленный аптайм |
| `dstfarm config [--set KEY=VALUE ...]` | показать или поменять настройки |

Первый прогон: `install` → `token <ТОКЕН>` → `S` в интерфейсе. Токен берётся в игре:
Account → Games → Servers → Add New Server.

## Что настроено под фарм

Мир (`worldgenoverride.lua`, шард Master):

* `day = "onlyday"` — вечный день, Чарли в темноте не тронет;
* вечная осень (`autumn = "verylongseason"`, остальные сезоны `noseason`) — ни мороза, ни перегрева;
* `hunger = "none"`, `sanity = "none"` — персонаж не голодает и не сходит с ума;
* гончие, охота, все рейдовые боссы, молнии, землетрясения, пожары — `never`;
* `world_size = "small"` — меньше сущностей, меньше CPU на длинном аптайме.

Кластер (`cluster.ini`):

* `game_mode = endless` — смерть не завершает мир;
* `pause_when_empty = false` — мир не встаёт на паузу;
* `tick_rate = 15`, пещеры по умолчанию выключены (второй шард удвоил бы нагрузку).

Супервизор: перезапуск после краша с настраиваемой паузой, опциональный плановый рестарт
по часу суток, логи шардов в `.runtime/logs/`, суммарный аптайм в `.runtime/state/uptime.json`.

## Структура

```
src/DstFarm.Core   конфиг, генерация кластера, steamcmd, супервизор
src/DstFarm.Cli    команды и полноэкранный интерфейс на Spectre.Console
tests              xunit-тесты на генерацию конфигов и профиль фарма
```

Настройки живут в `config.json` рядом с exe, кластер — в
`%USERPROFILE%\Documents\Klei\DoNotStarveTogether\<cluster>`.

## Порты

Master слушает UDP `server_port` (10999 по умолчанию) плюс steam-порты 27018/8768.
Для игры по интернету пробросьте UDP 10999 и 27018. Пещеры, если включены, занимают
11000 и 27019/8769.
