# Быстрый старт

English version: [../quickstart.md](../quickstart.md).

## 1. Что понадобится

* Windows x64.
* Аккаунт Klei (бесплатный) — из него берётся cluster token.
* Около 5 ГБ свободного места: серверный билд качается сжатым (~2.9 ГБ трафика)
  и разворачивается в ~4.2 ГБ. Klei отдаёт сервер как почти полный билд игры —
  со всеми ассетами и обеими версиями бинарника, 32- и 64-битной.
* Копия Don't Starve Together в Steam — чтобы зайти на сервер клиентом.
  Сам сервер ставится отдельно и Steam-аккаунта не требует.

.NET на целевой машине не нужен: сборка self-contained.

## 2. Поставить dstfarm

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/XYphrodite/dst-farm-server/main/install.ps1 | iex
```

Скрипт скачает последний релиз, сверит SHA-256, положит exe в
`%LOCALAPPDATA%\Programs\dstfarm` и добавит каталог в PATH. Права администратора не нужны.
Каталог задаётся параметром `-InstallDir`, подробности — в [README](../../README.ru.md#установка).

## 3. Получить cluster token

1. Запустите игру.
2. Account → Games → Servers → **Add New Server**.
3. Скопируйте длинную строку токена.

Второй способ, если страница аккаунта недоступна: в игре открыть консоль клавишей `~`
и выполнить `TheNet:GenerateClusterToken()` — файл `cluster_token.txt` появится в каталоге
настроек клиента, содержимое оттуда и нужно.

Без токена сервер не стартует, и дропы Klei не начисляются.

## 4. Поставить сервер DST

```
dstfarm install
```

Скачает steamcmd, затем серверный билд (app 343050, вход анонимный). Идёт прогресс-бар
с процентами и объёмом: `verifying update  1.5 ГБ / 4.2 ГБ  —  36.1%`.

Первый запуск steamcmd уходит на его собственное обновление, после которого он выходит,
ничего не установив. `dstfarm` это распознаёт и повторяет установку сам — так и задумано,
прерывать не нужно.

## 5. Настроить и запустить

```
dstfarm
```

Откроется полноэкранный интерфейс:

1. Стрелками дойдите до **Cluster token**, нажмите Enter, вставьте токен, Enter.
2. При желании поправьте имя сервера, пароль, флаги фарма.
3. `G` — записать настройки в файлы кластера.
4. `S` — запустить сервер.

Либо то же самое командами:

```
dstfarm token <ВАШ_ТОКЕН>
dstfarm init --force
dstfarm start
```

## 6. Зайти клиентом

В игре: Browse Games → вкладка **LAN** (если сервер на этом же ПК) или найдите его по имени
в общем списке. Про порты и нагрузку при работе на одной машине — [same-machine.md](same-machine.md). Заходите персонажем и оставляете клиент запущенным — именно за это время
и капают дропы.

Проверить, что всё живо:

```
dstfarm status
```

## 7. Остановить

`S` в интерфейсе или `dstfarm stop`. Сервер получает `c_shutdown(true)` и сохраняет мир
перед выходом — не убивайте процесс вручную, потеряете прогресс с последнего автосейва.

## Автозапуск при входе в Windows

```
dstfarm start --detach
```

Эту команду можно повесить в Планировщик заданий на триггер «При входе в систему».
